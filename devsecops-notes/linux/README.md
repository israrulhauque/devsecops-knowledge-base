# 🐧 Linux

## ⚡ Cheat Sheet / Quick Revision
- File permissions: `chmod`, `chown`, `umask` — rwx = 4/2/1
- Process mgmt: `ps aux`, `top`/`htop`, `kill -9 <pid>`, `systemctl`
- Networking: `netstat -tulnp`, `ss -tulnp`, `ip a`, `curl`, `dig`
- Logs: `/var/log/`, `journalctl -xe`
- Package managers: `apt` (Debian/Ubuntu), `yum`/`dnf` (RHEL/CentOS)
- Users/groups: `useradd`, `usermod -aG`, `/etc/passwd`, `/etc/shadow`
- Security/hardening: SSH key auth, disable root login, `ufw`/`iptables`, SELinux/AppArmor
