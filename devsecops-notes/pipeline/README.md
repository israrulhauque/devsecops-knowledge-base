# 🔁 CI/CD Pipeline

## ⚡ Cheat Sheet / Quick Revision
- CI = Continuous Integration (build + test on every commit)
- CD = Continuous Delivery/Deployment (auto release to staging/prod)
- Common tools: GitHub Actions, Jenkins, GitLab CI, Azure Pipelines, CircleCI
- GitHub Actions basics: `.github/workflows/*.yml`, `on:`, `jobs:`, `steps:`, `runs-on:`
- DevSecOps additions: SAST (SonarQube, CodeQL), SCA (Dependabot, Snyk), secrets scanning, container scanning (Trivy)
- Pipeline stages: Build → Test → Security Scan → Package → Deploy → Monitor
