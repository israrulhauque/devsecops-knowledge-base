# AWS

## ⚡ Cheat Sheet / Quick Revision
- Core: Accounts > Organizations, Regions & AZs
- Compute: EC2, Auto Scaling Groups, ECS/EKS, Lambda
- Identity: IAM (users, roles, policies), STS
- Networking: VPC, Subnets, Security Groups, NACLs, ALB/NLB
- Storage: S3 (storage classes), EBS, EFS
- Security: GuardDuty, Security Hub, KMS, Secrets Manager
- IaC: CloudFormation, Terraform (aws provider), CDK
- CLI: `aws configure`, `aws s3 ls`, `aws ec2 describe-instances`
