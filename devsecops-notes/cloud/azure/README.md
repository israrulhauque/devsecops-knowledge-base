# Azure

## ⚡ Cheat Sheet / Quick Revision
- Core: Resource Groups > Subscriptions > Management Groups
- Compute: VMs, VM Scale Sets, App Service, AKS
- Identity: Azure AD (Entra ID), RBAC, Managed Identities
- Networking: VNet, NSG, Load Balancer, App Gateway
- Storage: Blob, Files, Disks — redundancy (LRS/ZRS/GRS)
- Security: Azure Security Center / Defender for Cloud, Key Vault
- IaC: ARM templates, Bicep, Terraform (azurerm provider)
- CLI: `az login`, `az group create`, `az vm create`
