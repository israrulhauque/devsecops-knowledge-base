- Identity: Cloud IAM, Service Accounts
- Networking: VPC, Firewall Rules, Cloud Load Balancing
- Storage: Cloud Storage (buckets/classes), Persistent Disks
- Security: Security Command Center, Secret Manager, KMS
- IaC: Deployment Manager, Terraform (google provider)
- CLI: `gcloud init`, `gcloud config set project`, `gcloud compute instances list`
