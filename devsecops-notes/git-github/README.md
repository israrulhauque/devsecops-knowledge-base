# 🔧 Git & GitHub

## ⚡ Cheat Sheet / Quick Revision
- Basics: `git init`, `git clone`, `git status`, `git add`, `git commit -m ""`, `git push`, `git pull`
- Branching: `git branch`, `git checkout -b feature/x`, `git merge`, `git rebase`
- Undo: `git reset --soft/--hard`, `git revert`, `git checkout -- file`
- Collaboration: Fork → Branch → PR → Review → Merge
- GitHub features: Issues, Pull Requests, Actions (CI/CD), Branch Protection Rules
- `.gitignore` — files/folders to exclude from tracking
- Merge conflict resolution: edit conflict markers `<<<<<<<`, `=======`, `>>>>>>>`, then `git add` + `commit`
